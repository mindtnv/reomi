# Proposal

## Why

Счётчик карточек и серия доходят до человека только после открытия Reomi. `apps/web/src/lib/notify.ts` показывает локальное уведомление в этот момент, а согласие лежит в хранилище браузера. Закрытый телефон не получает ничего. Аудитория в основном в России, поэтому напоминание должно пережить правила Home Screen на iOS, push-endpoint Chrome на хосте Google и то, что push RuStore является Android SDK. Следующий полезный шаг состоит из серверного напоминания на уже поставленном PWA и письма для устройств, которые Web Push не примут.

## What Changes

- Появятся настройки напоминаний аккаунта и подписки Web Push по устройствам. Настройки не входят в снимок отмены оценки.
- На пользователя, канал и учебный день UTC уходит не больше одного дайджеста и одного предупреждения о серии. Учебный день остаётся UTC.
- Доставка идёт по Web Push с VAPID, без проекта Firebase, и через уже существующий почтовый провайдер. Если нет ключей VAPID или нет почтового провайдера, этот канал пропускается, а остальной API работает.
- Production service worker показывает push и по нажатию открывает повторение. Кэш по-прежнему пустой.
- Появится подсказка установки. Chromium использует `beforeinstallprompt`. iOS объясняет Share, затем Add to Home Screen. Подсказка не блокирует учёбу.
- Нынешнее уведомление при открытии и бейдж открытого приложения сохраняются.

## Capabilities

### New Capabilities

- `study-reminders`: настройки аккаунта, дневной дайджест, предупреждение о серии, подписки Web Push, письмо, изоляция пользователей и сбой, который не роняет API.
- `installed-pwa`: подсказка установки, service worker без кэша, который умеет показать push, и бейдж в пределах поддержки платформы.

### Modified Capabilities

Нет. Готовность уже требует безопасный снимок зарегистрированных воркеров. Тикер напоминаний входит в этот снимок и не меняет контракт готовности.

## Impact

Затрагиваются новая миграция в `packages/db`, модуль API с cookie-сессией, drain в `apps/api/src/index.ts`, одно добавочное поле воркера в `GET /ready`, `apps/web/src/app/sw.ts`, тексты настроек обоих языков и переменные VAPID. Production-процессу API нужен исходящий доступ к push-сервисам браузеров. Coolify остаётся одним веб-приложением и одним API.

Вне этой работы. Нет офлайн-кэша и синхронизации. Нет смены FSRS, формулы серии и учебного дня UTC. Нет приложений Tauri, Electron и Capacitor. Нет публикации в RuStore. Нет бота Telegram. Нет проекта Firebase. Нет записи этих настроек по personal access token. Нет второго напоминания того же вида в тот же учебный день UTC. Нет текста карточки, колоды или источника в напоминании.
