## ADDED Requirements

### Requirement: Personal tokens survive the product rename
Уже выданные персональные токены MUST оставаться действительными, пока их не отзовут или не истечёт срок. Новый секрет SHALL по-прежнему использовать префикс `nn_pat_`. Переименование MUST NOT переписывать сохранённые дайджесты, сроки, область доступа и факт отзыва. Секрет MUST NOT попадать в журналы из-за смены имени продукта.

#### Scenario: Existing token on the canonical API
- **WHEN** клиент вызывает MCP на `https://api.reomi.ru` с ранее выданным неотзванным токеном
- **THEN** сервер аутентифицирует того же пользователя и ту же область доступа

#### Scenario: Newly issued token
- **WHEN** пользователь создаёт персональный токен после переименования
- **THEN** секрет показывается один раз и начинается с `nn_pat_`
- **AND** последующие ответы списка токенов не содержат секрет

#### Scenario: Revoked token stays revoked
- **WHEN** токен отозван до переименования
- **THEN** после переименования он по-прежнему не авторизует MCP
